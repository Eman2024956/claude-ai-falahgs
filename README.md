# ورشة المشاهد ثلاثية الأبعاد (three.js)

مجموعة مشاهد ثلاثية الأبعاد صغيرة مبنية بمكتبة **three.js**. كل مشهد محفوظ في مجلد خاص به، ويمكن تغيير أي شيء فيه (لون، إضاءة، أثاث) ثم إعادة تشغيله.

## المشاهد الموجودة

| المشهد | الوصف |
|---|---|
| `01-hello-shapes` | مشهد تجريبي: مكعب وكرة وحلقة تدور فوق أرضية مع ضوء الشمس والظلال |
| `02-cozy-room-sunset` | غرفة جلوس دافئة وقت الغروب: شعاع شمس برتقالي يدخل من النافذة، أريكة، كرسي، طاولة، نبتة، مصباح مضيء |

---

## أولاً: التثبيت (مرة واحدة فقط)

### 1. تثبيت برنامج Node.js
هو برنامج مجاني يشغّل المشاهد على جهازك.

1. افتح الموقع: <https://nodejs.org>
2. اضغط الزر الأخضر الذي عليه كلمة **LTS** لتنزيل البرنامج.
3. افتح الملف الذي تم تنزيله واضغط **Next** حتى ينتهي التثبيت.

### 2. الحصول على ملفات المشروع
اختر إحدى الطريقتين:

- **من ملف ZIP:** اضغط بزر الفأرة الأيمن على الملف `three-scenes.zip` ثم اختر **Extract All** (استخراج الكل).
- **من GitHub:** افتح صفحة المستودع، اضغط الزر الأخضر **Code** ثم **Download ZIP**، ثم استخرج الملف.

### 3. فتح نافذة الأوامر داخل مجلد المشروع

- **ويندوز:** افتح مجلد المشروع، اكتب `cmd` في شريط العنوان أعلى النافذة ثم اضغط **Enter**.
- **ماك:** افتح برنامج **Terminal**، اكتب `cd` ثم مسافة، ثم اسحب مجلد المشروع إلى النافذة واضغط **Enter**.

### 4. تثبيت مكتبة three.js
اكتب هذا الأمر ثم اضغط **Enter**:

```bash
npm install
```

> إذا استخدمت ملف `three-scenes.zip` فالمكتبة موجودة بداخله مسبقاً، ويمكنك تخطي هذه الخطوة.

---

## ثانياً: تشغيل المشاهد

1. في نافذة الأوامر نفسها اكتب:

```bash
node tools/serve.mjs
```

2. ستظهر الرسالة: `Scenes running at http://localhost:5173/`
3. افتح المتصفح (Chrome أو Edge) واكتب في شريط العنوان:

```
http://localhost:5173/
```

4. ستظهر قائمة بالمشاهد. اضغط على اسم المشهد لفتحه.

**للإيقاف:** ارجع إلى نافذة الأوامر واضغط `Ctrl + C`.

### التحكم داخل المشهد

| الحركة | النتيجة |
|---|---|
| اسحب بزر الفأرة الأيسر | تدوير الكاميرا حول المشهد |
| عجلة الفأرة | تقريب وتبعيد |
| اسحب بزر الفأرة الأيمن | تحريك الكاميرا يميناً ويساراً |

---

## ثالثاً: تغيير شيء في المشهد

1. افتح مجلد المشهد، مثلاً: `scenes/02-cozy-room-sunset/`
2. افتح الملف `scene.js` ببرنامج **Notepad** (المفكرة).
3. في أعلى الملف يوجد قسم اسمه `SETTINGS` وهو قائمة «الأشياء التي يمكنك تغييرها».
4. غيّر القيمة التي تريدها، احفظ الملف (`Ctrl + S`)، ثم حدّث صفحة المتصفح (`F5`).

### إعدادات مشهد الغرفة الدافئة

| الإعداد | معناه | مثال |
|---|---|---|
| `wallColor` | لون الجدران | `'#e9d9c3'` |
| `rugColor` | لون السجادة | `'#b5533c'` |
| `sunColor` | لون ضوء الشمس | `'#ff8a3c'` |
| `sunStrength` | قوة شعاع الشمس (0 = بدون شعاع) | `9` |
| `sunHeight` | ارتفاع الشمس بالدرجات (أقل = شعاع أطول) | `24` |
| `sunTurn` | تحريك الشعاع نحو الأريكة (−) أو نحو الكاميرا (+) | `-8` |
| `lampOn` | المصباح: `true` مضيء، `false` مطفأ | `true` |
| `lampColor` | لون ضوء المصباح | `'#ffb066'` |
| `lampStrength` | قوة ضوء المصباح | `5` |
| `roomGlow` | الإضاءة العامة الناعمة في الغرفة | `1.0` |
| `brightness` | سطوع الصورة كاملة | `1.0` |
| `sky` | صورة السماء خلف النافذة (`qwantani_sunset` أو `belfast_sunset`) | `'qwantani_sunset'` |
| `skyBrightness` | سطوع السماء خلف النافذة | `0.5` |

> الألوان تُكتب برمز يبدأ بعلامة `#`. للحصول على رمز أي لون ابحث في Google عن **color picker**.

## رابعاً: تنظيم المجلدات

| المجلد | محتواه |
|---|---|
| `scenes/` | المشاهد، كل مشهد في مجلد (`index.html` الصفحة، `scene.js` المشهد) |
| `lib/` | ملفات مشتركة بين المشاهد (الكاميرا، التحكم بالفأرة، تحميل النماذج) |
| `assets/` | النماذج والخامات والسماء المجانية، وقائمة مصادرها في `assets/CREDITS.md` |
| `renders/` | صور جاهزة لكل مشهد من عدة زوايا |
| `tools/` | أدوات التشغيل والتنزيل |

### إضافة مشهد جديد
1. انسخ المجلد `scenes/01-hello-shapes` وأعطِ النسخة اسماً جديداً، مثل `03-my-scene`.
2. عدّل الملف `scene.js` داخل المجلد الجديد.
3. سيظهر المشهد تلقائياً في القائمة على `http://localhost:5173/`.

### تنزيل نماذج مجانية إضافية من Poly Haven

```bash
node tools/get-polyhaven.mjs model sofa_03
```

```bash
node tools/get-polyhaven.mjs texture herringbone_parquet
```

```bash
node tools/get-polyhaven.mjs hdri qwantani_sunset 2k
```

اسم النموذج تجده في آخر رابط صفحته على موقع <https://polyhaven.com>.

## خامساً: حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| رسالة `node is not recognized` أو `command not found` | برنامج Node.js غير مثبت. أعد الخطوة 1 ثم أغلق نافذة الأوامر وافتحها من جديد. |
| الصفحة لا تفتح في المتصفح | تأكد أن نافذة الأوامر ما زالت مفتوحة وأن الأمر `node tools/serve.mjs` يعمل. |
| صفحة بيضاء أو سوداء | لا تفتح الملف `index.html` بالنقر المزدوج. افتح المشهد دائماً من العنوان `http://localhost:5173/`. |
| رسالة `Cannot find package 'three'` | اكتب الأمر `npm install` داخل مجلد المشروع. |
| رسالة `address already in use` | المشاهد تعمل مسبقاً في نافذة أخرى. أغلق تلك النافذة ثم أعد المحاولة. |
| التغيير لا يظهر | احفظ الملف أولاً (`Ctrl + S`) ثم حدّث الصفحة (`F5`). |
